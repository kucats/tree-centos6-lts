tree CentOS 6 LTS security updates

Community backports of security fixes for the final CentOS 6.10 packages. Packages and repository metadata are GPG-signed. Source and test evidence: github.com/kucats/tree-centos6-lts.

curl -o /etc/yum.repos.d/tree-centos6-lts.repo https://kucats.github.io/tree-centos6-lts/tree-centos6-lts.repo
yum --security check-update
yum update sudo

No warranty. Coverage is limited to the packages listed in the repository's config/release.json; CentOS 6 remains end-of-life.
